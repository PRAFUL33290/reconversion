# 🏛️ Praful City CMS

> Projet pédagogique de reconversion professionnelle vers le développement web et la communication numérique pour les collectivités territoriales.

---

# 🎯 Objectif

Je travaille actuellement comme animateur territorial et je souhaite évoluer vers un poste de :

- Chargé de communication numérique
- Webmaster
- Gestionnaire de site internet
- Assistant communication digitale
- Développeur web junior en collectivité

Afin d'acquérir des compétences concrètes, j'ai choisi de développer **Praful City CMS**, un système de gestion de contenu inspiré des besoins réels des mairies.

L'objectif n'est pas uniquement de créer un site internet, mais de comprendre l'ensemble des technologies utilisées pour concevoir et maintenir un portail municipal moderne.

---

# 📚 Une formation par la pratique

Ce projet constitue mon parcours d'apprentissage.

Chaque fonctionnalité est développée progressivement afin de comprendre :

- les principes techniques ;
- les bonnes pratiques ;
- la sécurité ;
- l'accessibilité (RGAA) ;
- le RGPD ;
- le référencement (SEO) ;
- la maintenance d'un site institutionnel.

Chaque module est réalisé comme un véritable projet professionnel.

# 🎓 Mon objectif professionnel

À travers ce projet, je souhaite démontrer ma capacité à :

- développer une application web complète ;
