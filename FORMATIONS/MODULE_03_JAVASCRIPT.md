# Module 3 --- JavaScript : rendre le site interactif

> **Praful City CMS -- Parcours de formation**

## 🎯 Objectif

Découvrir JavaScript afin d'ajouter des interactions au site Ville de
Nova.

## Compétences

-   Comprendre le rôle de JavaScript
-   Déclarer des variables
-   Utiliser des conditions
-   Utiliser des boucles
-   Créer des fonctions
-   Manipuler le DOM
-   Gérer les événements

------------------------------------------------------------------------

## Projet

Ajouter :

-   un bouton Retour en haut ;
-   un bouton qui affiche/masque les actualités ;
-   un message de bienvenue dans la console.

------------------------------------------------------------------------

## Exercices

1.  Créer `js/app.js`
2.  Le relier à `index.html`
3.  Afficher `console.log("Bienvenue sur Ville de Nova");`
4.  Ajouter un bouton qui masque les actualités.
