      Les fondamentaux

      Comprendre la règle CSS

      Une règle CSS sélectionne un ou plusieurs éléments HTML, puis lui applique des propriétés visuelles.

      .service-card {
        background-color: #ffffff;
        border-radius: 1rem;
        padding: 1.5rem;
      }

      02

      Dimensionner

      Maîtriser le box model

      Chaque élément HTML est une boîte composée du contenu, du padding, de la bordure et de la marge extérieure.

      margin
      border
      padding
      contenu
      width × height
      Box model recommandé
      * {
    box-sizing: border-box;
}

.card {
    width: 100%;
    padding: 1.5rem;
    border: 1px solid #dbe3ec;
    margin-bottom: 1rem;
}
      i
      Pourquoi border-box ?

      La largeur déclarée inclut alors le padding et la bordure. Les dimensions deviennent beaucoup plus prévisibles.

      Créer une identité

      Typographie, couleurs et variables

      Une charte graphique limitée et cohérente facilite la lecture. Les variables CSS centralisent les décisions visuelles.

      Dimensions relatives à la fenêtre.

      clamp()

      04

      Aligner

      Construire avec Flexbox

      Flexbox organise des éléments sur un axe principal. Il est idéal pour une navigation, une rangée de boutons ou l’alignement interne d’une carte.

      Logo NovaActualitésAgendaServices

      display: flex · align-items: center · gap: 1rem

      Navigation avec Flexbox
      .main-navigation {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 1rem;
}
      flex-direction

      Choisit l’axe : ligne ou colonne.

      justify-content

      Aligne sur l’axe principal.

      align-items

      Aligne sur l’axe secondaire.

      gap

      Définit un espace régulier entre les éléments.

      flex-wrap

      Autorise le passage sur plusieurs lignes.

      flex

      Contrôle l’espace occupé par un enfant.

      05

      Composer

      Créer des grilles responsives

      CSS Grid contrôle simultanément les lignes et les colonnes. Il convient parfaitement aux actualités et aux services municipaux.

      ActualitéCulture
      ActualitéTravaux
      ActualitéEnvironnement
      ActualitéJeunesse
      ActualitéSport
      ActualitéCitoyenneté
      Grille automatique
      .news-grid {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(240px, 1fr));
    gap: 1.5rem;
}
      i
      Une grille déjà flexible

      auto-fit et minmax() permettent aux cartes de se réorganiser selon la place disponible.

      06

      Tous les écrans

      Concevoir en responsive

      Commence par une mise en page simple pour le mobile, puis enrichis-la quand l’espace disponible augmente : c’est l’approche mobile first.

      Mobile
      Tablette
      Ordinateur
      Media query
      .service-grid {
    display: grid;
    grid-template-columns: 1fr;
}

@media (min-width: 768px) {
    .service-grid {
        grid-template-columns: repeat(3, 1fr);
    }
}

      Composant bouton
      .button {
    display: inline-flex;
    padding: .75rem 1.25rem;
    border-radius: var(--radius);
    transition: transform .2s ease;
}

.button--primary {
    background: var(--color-action);
    color: white;
}

.button:hover {
    transform: translateY(-2px);
}

.button:focus-visible {
    outline: 3px solid #f59e0b;
}
      !
      Le focus est indispensable

      Un effet de survol ne suffit pas. Les utilisateurs au clavier doivent toujours voir où ils se trouvent.
