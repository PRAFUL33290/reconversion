      Les coulisses

      MySQL

      La base de données

      MySQL est l’armoire de rangement du site : les actualités, les événements, les comptes rendus, les comptes utilisateurs y sont stockés sous forme de tables, et on les interroge avec le langage SQL.

      D’où ça vient

      1. SQL naît chez IBM dans les années 1970, à partir des travaux d’Edgar Codd sur le modèle relationnel : ranger les données dans des tables liées entre elles plutôt que dans des fichiers isolés.

      2. MySQL apparaît en 1995, développé en Suède. Gratuit, rapide et simple à installer, il devient le compagnon naturel de PHP et l’un des piliers du web des années 2000.

      3. Racheté par Sun puis par Oracle, il coexiste aujourd’hui avec son descendant libre MariaDB. La logique reste la même, et elle se réapprend d’un système à l’autre.

      Ce qu’il faut retenir

      Des tables et des relations

      Une table « actualités », une table « auteurs », et un lien entre les deux : les données ne sont saisies qu’une fois.

      SQL est déclaratif

      On décrit ce que l’on veut obtenir, pas la manière de le chercher.

      La sauvegarde fait partie du métier

      Une base sans sauvegarde régulière est un risque, pas un outil.

      Dans ce projet

      Indispensable dès qu’un site municipal cesse d’être une vitrine figée pour devenir un outil que les agents alimentent au quotidien.
