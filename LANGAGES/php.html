      Les coulisses

      PHP

      Le code côté serveur

      PHP travaille sur le serveur, avant que la page n’arrive au visiteur : il va chercher les données dans la base, assemble le HTML, gère les connexions et les formulaires. Le visiteur ne voit jamais ce code.

      D’où ça vient

      1. 1994 : Rasmus Lerdorf écrit quelques outils pour suivre les visites de sa page personnelle et les nomme Personal Home Page Tools.

      2. PHP 3 puis PHP 4, à la fin des années 1990, en font un vrai langage de programmation. Avec Apache et MySQL, il équipe une grande partie du web et récolte au passage une solide réputation de désordre.

      3. PHP 7 (2015) puis PHP 8 changent la donne : bien plus rapide, mieux typé, outillé pour un code propre. Aujourd’hui, une large majorité des sites du monde tourne encore sur PHP — WordPress en tête.

      Ce qu’il faut retenir

      Exécuté avant l’affichage

      Le serveur produit une page HTML finie ; le code source reste invisible.

      Le langage de WordPress

      Comprendre PHP, c’est pouvoir dépasser les réglages d’un thème et intervenir réellement.

      La sécurité est centrale

      Toute donnée envoyée par un utilisateur doit être vérifiée avant d’être utilisée.

      Dans ce projet

      C’est la charnière du parcours : le passage de « faire une page » à « faire un outil » que des agents utilisent chaque semaine.
